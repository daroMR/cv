# AGENTS.md — CV

Personal CV/portfolio site for Hesvin Dario Molina Rios. Static HTML+CSS+JS, deployed via GitHub Pages.

## Branches & deploy

- **`dev`** (default) — development. **`prod`** — deployed to GitHub Pages at `https://daromr.github.io/cv/`.
- GitHub Pages builds from `prod` branch. CI: no workflows in repo — Pages builds are triggered externally.

## Key structure

| Path | Purpose |
|---|---|
| `index.html` | Main CV page: profile, experience, education, action bar (PDF download, Telegram, LinkedIn) |
| `portafolio.html` | Portfolio gallery — single-page JS app with carousel, masonry wall, lightbox |
| `mantenimiento.html` | Maintenance placeholder — portfolio currently hidden from `index.html` |
| `js/index.js` | Button event handlers (download PDF, Telegram, LinkedIn) |
| `css/index.css` | CV page styles |
| `css/portafolio.css` | Portfolio dark-theme styles |
| `galeria/` | Gallery assets (images, PDFs, thumbs) |
| `galeria/generate_gallery_index.py` | **Run this after adding assets**: generates `gallery_index.json` |
| `visor/` | WebGL Unity Viewer build |
| `reel/` | WebGL Unity Showreel build |
| `descargas/` | Downloadable CV PDF + Reel.zip |

## Gallery loading (portafolio.html)

Three fallback strategies, tried in order:
1. `galeria/gallery_index.json` (preferred — generated by `generate_gallery_index.py`)
2. `galeria/gallery_grid.html`
3. Directory listing fallback

After adding/removing gallery files:
```bash
python galeria/generate_gallery_index.py
```

## Portfolio button currently hidden

The portfolio button in `index.html` has `hidden` attribute. To re-enable, remove it. `mantenimiento.html` is the current redirect.

## Cache busting

CSS/JS `<link>` and `<script>` tags use query param `?v=YYYYMMDD`. Update the date when deploying changes.

## Dev commands

There are no build toolchain, package.json, lint/typecheck config, or CI workflow files. The site is plain static HTML — open `index.html` in a browser to preview. No server required.

## Style conventions

- HTML: Spanish (`lang="es"`). Tailwind CSS via CDN on `index.html`. Portfolio is standalone CSS.
- The commit history is sparse (single commit on `dev`). Make meaningful commits.
- No formatter/linter config exists — wrap manually.
