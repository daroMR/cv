# daroMR.github.io

Este repositorio contiene el código fuente del Currículum Vitae de Hesvin Darío Molina Ríos, desarrollado como un sitio web moderno y visualmente atractivo.

## Características

- Diseño responsive y moderno usando [Tailwind CSS](https://tailwindcss.com/) y estilos personalizados.
- Alternancia entre tema claro y oscuro.
- Descarga del CV en PDF directamente desde la web.
- Acceso rápido a LinkedIn.

## Visualización

Abre el archivo `index.html` en tu navegador para ver el CV.

## Generar PDF

Haz clic en el botón **"Descargar CV en PDF"** para obtener una versión imprimible del currículum.

## Tecnologías utilizadas

- HTML5, CSS3, JavaScript
- [Tailwind CSS (CDN)](https://cdn.tailwindcss.com/)
- [jsPDF](https://github.com/parallax/jsPDF) y [html2canvas](https://github.com/niklasvh/html2canvas) para exportar a PDF
